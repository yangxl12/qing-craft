- 新建 `~/.workbuddy/mcp.json`，添加 `wechat-devtools`（command: `uvx wechat-devtools-mcp`，v0.9.16）。
- 与 codebuddy（`~/.codebuddy/mcp.json`）、codex（`~/.codex/config.toml`）配置一致，可三端共用：
  MCP 是 stdio 子进程，各客户端各自 spawn 实例，互不干扰；共用的是底层微信开发者工具 IDE，建议串行操作。
- 必需环境变量：`WECHAT_DEVTOOLS_CLI`（`D:\微信web开发者工具\cli.bat`）、`WECHAT_PROJECT_PATH`。
- 注意：全局配置里 `WECHAT_PROJECT_PATH` 写死为 `D:\my-project\qing-craft`；
  codex 那份指向 `D:\my-project\digital-ceramics`。切换小程序项目时需改此变量。
- 生效方式：需在 WorkBuddy 连接器管理页的自定义连接器入口点击「信任」后启用。
