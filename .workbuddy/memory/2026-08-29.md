## 制坯陶轮简化 + 成品展台重做 + 消除跳转闪烁

- 需求：①「?」弹窗背景不要透明（与 i 弹窗一致）且 × 关不掉；②厚度下方 3 个形态按钮宽度降到 1/4 并靠右与厚度块右对齐；③制坯陶瓷底部的陶轮太复杂，改成简洁旋转圆盘，与陶瓷同向同速；④成品展台放大、重做透视与光线；⑤删掉跳转时闪现的「成品页」。
- 实现要点：
  - **× 关不掉的根因**：`.gesture-map`（`studio.wxml` 第 179 行）DOM 顺序在 `.shaping-controls`（第 197 行）**之前**，两者同为 `z-index:30`，后一个兄弟覆盖前一个 → 弹窗右上角的 × 被泥壁厚度面板整个压住。修法与上次 `.stage-tips` 完全同类：给 `.gesture-map` 提到 `z-index:31`。
    → 教训：制坯页任何新的浮层弹窗都要显式提 z-index，不能直接吃 `shaping.wxss` 顶部那组 `z-index:30` 的默认值。
  - 弹窗不透明：文件末尾已有 `.gesture-map, .stage-tips { background: var(--color-workshop-surface); }` 兜底，两弹窗一致。
  - 形态按钮：`.shaping-controls` 改 `display:flex; flex-direction:column; align-items:flex-end`；`.form-switcher` 由 `width:100%` 改 `width:auto` + `align-items:stretch`；`.form-chip-hit` 由 `width:100%` 改 `72rpx`（窄屏 64rpx），`.form-chip` 字号降为 micro、`padding:0`。
  - 陶轮：删掉旧 7 层家具式结构（contact-shadow/wheel-basin/wheel-head/machined-rings/slip-mark/wheel-glint/wheel-front-lip），改为 `wheel-plate`（edge + face + spin + contact）四层圆盘；`--wheel-squash: 0.21875`（112/512）。
    - 旋转周期直接复用引擎 `--wheel-period:{{wheelPeriodMs}}ms`，与陶器 RPM 严格一致。
    - 方向对齐：引擎 `rotateY(-turntableAngle)` = 俯视顺时针 = 正面看前缘向左；CSS `scaleY(squash) rotate(0→360deg)`（屏幕顺时针）前缘同样向左 → 同向。若实机发现反向，只需把 `rotate(360deg)` 改成 `rotate(-360deg)`。
    - 必须保留 `#wheelContact` 锚点，引擎靠它定位器物底部。
  - 成品展台：6 层家具式底座 → 圆柱四层（floor-shadow / wall / top / top-groove）+ cast + ao；尺寸 520×120 → 580×190（窄屏 470 → 520）；透视比统一 0.212（顶面 118/557）；展柜主光左上 → 顶面暖斑在 28%/24%、器物投影偏右上、地面落影偏右、侧壁水平渐变亮部在左。
  - 跳转闪烁：`finishKiln()` 中低温烤花（refire）分支原来先 `setData({kiln:false})` 触发 stage 6「成品」空白页渲染一帧、再在回调里 `redirectTo` → 改为**直接** `wx.redirectTo`，只在 `fail` 回调里补 setData。
- 坑：
  - `scripts/check-ui-tokens.mjs` 对 `result.wxss`/`base.wxss` 强制「只引用 Token」，新增颜色必须先在 `styles/tokens.wxss` 建 `--ui-plinth-*` / `--ui-wheel-*` 令牌，不能直接写 rgba/hex。
  - `tests/ui-stages-3-5.test.cjs` 断言写死了旧 class（`plinth-front`/`plinth-top-inset`），改结构后必须同步更新断言，否则测试红。
  - 微信开发者工具 MCP：`wechat_ide(open)` 会报「返回码 9」，但 IDE 其实已在运行，直接 `wechat_automator(start)` + `wechat_navigate` 可用；`wechat_screenshot` 这次在 studio（webgl canvas）也能成功，未复现上次超时。
  - 自动化会话容易在若干次调用后莫名回落到 `pages/index/index`；`set_data` 的返回 `path` 可能与实际页面不符，用 `page_stack` 复核。
