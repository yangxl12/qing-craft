## 事故与恢复记录

- 为判断一个检查项是否为既有问题执行了 `git stash push`，随后 `.git/objects` 与 `.git/refs` 内容被清空，git 报 “not a git repository”。
- 恢复方式：`mkdir .git/objects/{info,pack}` 与 `refs/{heads,remotes/origin,tags}` → `git fetch origin main` 拉回 912 个对象 → 用 `git update-ref` / 直接写文件恢复 `refs/heads/main` 与 `refs/remotes/origin/main`（均指向 4ccd683，与事故前 HEAD 一致，且该提交已推送远端）→ `git fsck --connectivity-only` 无报错。
- 结论：本环境不要用 `git stash`；需要对比基线时改用 `git show HEAD:<file>`。
