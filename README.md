# 掌心窑 v1

基于《微信陶艺小程序产品需求文档_PRD.md》实现的原生微信小程序垂直切片。项目不依赖外部 3D 包，使用 TypeScript 与最小 WebGL 渲染层生成轴对称陶坯。

## 已实现

- 游客直接体验；5 类器形、3 种泥料、轻松/自由模式与练泥交互。
- 48 点径向剖面、48/64/88 圆周采样的程序化陶坯网格。
- 陶坯命中塑形、背景观察、双指缩放/旋转、开口与 8 种制坯工具。
- 最小半径、斜率限制、50 步撤销/重做与 500ms 防抖自动保存。
- 3 个风格包、15 个母纹样、6 条边饰和 6 套器形自适应构图；支持 5 个装饰层、8 枚落印、分区、位置、大小、旋转、疏密、对称与烧后预览。
- 刻花、印花、釉下青花和釉上点彩可独立叠加；写款支持 5 种版式、3 种表现、2 种字形、四类内容和最多 3 枚本机私款。
- schema 2 参数化保存、schema 1 恢复副本与显式迁移、50 步撤销/重做和 500ms 防抖自动保存。
- 成品 360° 查看、纹样/工艺/寓意信息卡、三种展台光氛围、作品图/纪念海报、相册保存、微信分享入口和“沿用纹样再做一件”。
- 本机作品集、草稿恢复、命名、复制和删除；WebGL 不可用时仍可套版、配色、写款和生成带纹样摘要的兜底图。
- 匿名本地漏斗事件，不记录触摸点、笔迹、作品名或图片内容。

## 运行

1. 在微信开发者工具中导入本目录。
2. 本地体验可使用测试号；预览或上传前，将 `project.config.json` 的 `appid` 换成真实小程序 AppID 并登录开发者工具。
3. `npm install` 后可运行 `npm run typecheck` 和 `npm test`。

当前属于可交互本地原型。云同步、服务端内容安全、声音资源和真机性能矩阵仍需在有 AppID、设备与后端环境后接入；装饰资产当前为项目原创的程序化轮廓，来源记录见 `assets/decoration/ASSET_LICENSES.md`。
