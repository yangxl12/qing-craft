# 装饰资产来源与许可

本目录用于记录进入小程序包体的装饰资产来源。

- 首发 15 个母纹样、6 条边饰，以及装饰材料库中的纹样/刻花各 20 件精选作品，由 `core/decoration.ts` 和 `core/pottery-engine.ts` 中的程序化几何、构图参数与着色规则生成，为本项目原创实现；未描摹馆藏照片，也未引入第三方图片。精选作品名称采用中国陶瓷常见的传统纹饰题材描述，不宣称复刻具体馆藏文物。
- 装饰材料库“图案”页的 20 幅青花圆景来自用户于 2026-08-30 上传并明确要求用于本项目的 `ChatGPT Image 2026年8月30日 21_33_54 (1).png` 与 `ChatGPT Image 2026年8月30日 21_33_54 (2).png`。项目只做源像素裁切、盘沿与外框清除、背景透明度提取、主体缩放与尺寸压缩，没有重绘画面。20 个透明独立文件位于 `assets/decoration/patterns/items/`，运行时图集为保留逐像素透明度的 `assets/decoration/patterns/blue-white-pattern-atlas.png`，顺序和来源记录在同目录 `manifest.json`。独立文件在上传配置中排除，避免与图集重复占用小程序包体。
- “清雅楷意”和“篆意印文”使用设备内置的宋体/楷体族进行运行时排版，小程序包不再分发字体文件；字体不可用时回退到系统 `serif`。两种字形名称描述的是排版意向，不指向具体在世艺术家或历史真品。
- 写款在本地离屏 Canvas 中生成透明纹理，只保存文字与版式参数，不保存或上报生成纹理。
- `assets/studio-decoration-workshop.jpg` 于 2026-08-26 使用 Codex 内置 ImageGen 为本项目生成。提示词要求“古风唯美写实陶瓷工坊、纵向 9:16、中心留白承载 3D 瓷器、下部低细节承载半透明操作卡、月白/墨青/木色/窑火色、无人物/文字/标志/水印”；生成 PNG 后以 JPEG 质量 84 压缩进入小程序包。

后续若加入 SVG、位图或字体文件，必须在本文件逐项补充作者、来源、许可范围和对应文件路径后才能进入包体。
