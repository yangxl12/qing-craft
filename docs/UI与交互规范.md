# 泥火青花 UI 与交互规范

本规范用于维护现有微信小程序的视觉与交互一致性。新增或修改页面时，优先复用现有 Token、`app-nav`、`ui-icon` 和基础样式。

## 1. 设计原则

- 产品是移动端陶瓷创作工坊；器物是视觉主角，界面保持安静。
- 用户始终应知道：当前工序、器物状态、下一步操作。
- 气质使用天青、月白、松烟、窑火和留白；避免满屏仿古装饰、印章、祥云、玻璃拟态。
- 文案使用真实动作，例如“开始制坯”“完成装饰”“保存到相册”，不使用脱离上下文的“开始”“完成”。

## 2. 视觉基础

### 场景

- 内容场景：首页、作品集、设置、信息面板、导出预览：浅色月白背景、松烟墨文字。
- 工坊场景：创作台、成品展台：深色松烟背景、真实场景图片。
- 两种场景只改变环境亮度，不改变导航、按钮、图标、圆角和状态语义。

### 颜色

页面只使用语义 Token，不直接新增色值：

| 语义 | Token | 用途 |
| --- | --- | --- |
| 主操作 | `--ui-action` | 主按钮、链接、焦点 |
| 页面文字 | `--ui-text` / `--ui-text-secondary` | 标题正文 / 辅助说明 |
| 表面 | `--ui-bg` / `--ui-surface` | 页面背景 / 卡片面板 |
| 边界 | `--ui-border` | 边框、分隔线 |
| 选中 | `--ui-selected-surface` | 选中底色，配合边框或勾选 |
| 危险 | `--ui-danger` | 删除、不可逆操作、失败 |
| 朱砂 | `--ui-accent` | 品牌印记和少量文化强调 |
| 窑火 | `--color-kiln` | 窑烧过程和火候信息 |

朱砂只作点缀，窑火只用于烧制；选中、成功、错误和进度不能只靠颜色表达。

### 字体

- 展示标题使用宋体：`--font-display`。
- 正文、按钮、菜单使用系统无衬线：`--font-body`。
- 温度、尺寸、进度等短数字使用：`--font-data`。
- 默认正文 `28rpx`；辅助文字不小于 `24rpx`；操作文字不小于 `28rpx`。
- 只使用 400、500、600 三档字重；中文正文不额外加字距。

### 图标与表面

- 图标统一使用本地 `ui-icon`，不得使用 Emoji、随机 Unicode 或在线字体图标。
- 图标基准 `24×24`，常用尺寸 `32/40/48rpx`；图标按钮可点击热区为 `88×88rpx`，创作台密集区最低 `80×80rpx`。
- 普通操作使用描边图标；成功、错误、勾选等明确状态可使用填充图标。
- 卡片/按钮/抽屉圆角分别优先使用 `radius-md` / `radius-lg`；圆形只用于图标按钮和状态胶囊。
- 常规边框 1rpx；选中边框 2rpx，并同时提供底色、勾选或文字线索；单个组件最多一层外阴影。

## 3. 布局规范

- 页面遵循“安全区 → 自定义导航 → 页面题头 → 主内容 → 底部操作区”的结构。
- 常规左右边距 `32rpx`，窄屏可用 `24rpx`；常规间距使用 `8/16/24/32/40/48/64rpx`。
- 所有底部固定区域包含 `env(safe-area-inset-bottom)`，不得遮挡内容或系统胶囊。
- 内容页使用 4 列流式布局；创作台装饰菜单保持左侧材料库、右侧当前图层约 `3:2`。
- 创作台分层为：背景环境 → 工序导航 → 器物舞台 → 工具浮层 → 抽屉/底部操作。背景不响应触摸，工具层阻止事件穿透。
- 抽屉展开、全屏和短屏重排只调整画布、相机和居中参数，不改变器物形状、比例和视觉尺度；抽屉变化后重新计算画布尺寸。

响应式验收覆盖 `320×568`、`375×812`、`430×932`：先保证安全区、主操作、器物完整和触控热区，再收紧间距、折叠辅助内容，最后处理装饰；不得把正文缩到 `24rpx` 以下或按钮缩到 `80rpx` 以下。

## 4. 组件与状态

- 一操作区最多一个视觉主按钮；次按钮、文字按钮和危险按钮要有明确层级。
- 主要流程和危险操作必须有可见文字，图标只作辅助；所有图标按钮都要有稳定容器和 `aria-label`。
- 交互组件至少覆盖：默认、按下、禁用；按需覆盖选中、加载、成功、错误。
- 按下状态在 `120ms` 内响应，容器轻微下移或缩放 `0.98`；直接拖动不加过渡，必须跟手。
- 加载时保留按钮宽度并禁止重复提交；失败要保留用户数据并提供重试。
- 选择状态至少同时使用两种线索：颜色/底色、边框、勾选、位置或文字。
- 保存状态统一为“保存中 / 已保存 / 保存失败，点此重试”。

## 5. 创作台交互

- 七道工序始终显示当前工序、进度位置和下一步；底部主操作使用明确的工序动作。
- 单指只在当前工序允许时操作器物或纹样；双指统一用于相机环看和缩放。
- 装饰全屏模式禁止单指移动纹样，只允许双指视角与缩放。
- 工具浮层的拖动区域与折叠按钮分离；折叠按钮不能触发拖动。
- 长按只作为快捷方式；作品集必须提供可见的“整理”入口。
- 装饰材料库与当前图层保持真实数据同步；复制编号、图层选择、撤销/重做、保存/恢复必须持续有效。
- 删除、返回并丢失装饰等不可逆操作先确认；取消确认不得改变作品、选择或历史。
- 窑烧保留为主要环境动效；“跳过”是次级操作，不与进度争夺视觉层级。

## 6. 动效、反馈与无障碍

- 动效时长：按压 `120ms`，局部选中/展开 `180ms`，抽屉/模态 `280ms`，工序交接 `420ms`。
- 一次操作只保留一个主要运动；优先使用 `transform` 和 `opacity`，不使用无限循环装饰动画。
- “减少动态”对所有页面生效：停止扫光、粒子、热浪和自动转盘；直接操作仍即时跟手。
- 轻触反馈仅用于重要选择、工具切换和吸附；完成工序、删除确认、题款落印可用中等反馈；普通导航、滚动和连续拖动不反馈。
- 优先使用原生 `button`、`radio`、`checkbox`；自定义可点击元素必须有可验证的角色、名称、选中/禁用状态和代码守卫。
- 装饰性图片、纹理和分隔线标记为隐藏；弹窗打开后背景不可操作，并提供明确关闭按钮。
- 普通文字对比度不低于 `4.5:1`，大字和关键非文本控件不低于 `3:1`。

## 7. 最小验收清单

- 三档屏幕无横向滚动、按钮裁切、安全区遮挡或系统胶囊重叠。
- 页面主操作、危险操作、导航、选择和状态的视觉语义一致。
- 创作台器物比例稳定，菜单不遮挡主要操作区，WebGL 与兜底路径行为一致。
- 破坏性操作可取消且数据不变；异步操作可感知、不可重复提交、失败可恢复。
- 关键路径可通过微信开发者工具和真机完成视觉、触控及辅助技术冒烟验证。
