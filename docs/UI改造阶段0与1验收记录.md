# UI 改造阶段 0 与阶段 1 验收记录

> 实施日期：2026-08-28  
> 对应基线：`docs/UI与交互规范及改造实施计划.md`

## 1. 阶段 0：基线与 P0 修复

已完成：

1. 核心页面改造前截图保存在 `screenshots/ui-phase-0-baseline/`：首页、作品集、设置、制坯、成品页。
2. 成品页底部操作改为可收缩 Grid，常规宽度使用 `minmax(0, 1.35fr) minmax(0, 1fr) 88rpx`；`340px` 及以下由主按钮独占首行，纪念海报与分享位于第二行。
3. 装饰菜单改用高不透明瓷白表面；展开/收起、调校、加减、上一步和完成操作的关键热区提升到 `80–88rpx`，操作文字同步提高。
4. 隐藏尚无声音引擎支持的“环境声音”，启动时清理旧 `sound` 偏好；设置页不再展示无效能力。
5. 创作台接入 `guidance`：轻松引导显示教学、停滞、风险和错误提示；仅必要提示与自由创作隐藏教学提示，但保留风险、错误与帮助入口。
6. 作品删除、成品删除、装饰返回制坯共用确认边界；无选择删除具备 `disabled`、`aria-disabled` 与处理器守卫。

开发者工具实测：装饰返回弹窗取消前后均为 `stage=1`、`layers=1`、`confirming=false`，取消没有改变作品与历史入口状态。

## 2. 阶段 1：设计基础设施

已新增：

- `styles/tokens.wxss`：浅/深场景色彩、字体、间距、圆角、阴影、层级和动效 Token。
- `styles/primitives.wxss`：按钮、表面、标签页、选择项和状态基础类。
- `styles/utilities.wxss`：页面边距、安全区、最小热区、截断、读屏隐藏和减少动态工具类。
- `components/ui-icon/` 与 `assets/icons/`：24 枚本地描边 SVG 及统一组件出口。
- `components/app-nav/` 与 `utils/ui-metrics.ts`：统一导航热区、状态栏、胶囊避让和异常回退。
- `pages/ui-preview/`：不设产品入口的浅/深场景基础设施预览页。
- `scripts/check-ui-tokens.mjs`：10 组对比度、24 枚图标、基础样式硬编码色和旧页面色值预算门禁。

微信开发者工具对 WXSS SVG mask 未稳定显示，因此 `ui-icon` 使用本地 SVG `image` 渲染，并按明暗场景提供统一 tone；该路径已在设置返回、成品分享和装饰调校中实测显示。
