# 泥火青花项目介绍

## 项目定位

“泥火青花”是一个原生微信陶艺创作小程序。用户可在手机上完成制坯、装饰、上釉、烧制和彩绘，并在作品集中继续编辑或查看成品。

项目不依赖第三方 3D 引擎，使用 TypeScript、WXML/WXSS 和 WebGL 实现陶坯建模与渲染；作品、设置和匿名使用事件均保存在本机。

## 核心流程

`首页 → 制坯 → 装饰 → 上釉 → 高温烧制 → 釉上彩绘 → 低温烤花 → 成品页 / 作品集`

创作数据统一存放在 `PotteryWork` 中。创作台支持撤销、重做和 500ms 防抖自动保存；当前数据版本为 schema 2，并兼容旧版 schema 1 作品。

## 代码结构

| 目录        | 职责                                                         |
| ----------- | ------------------------------------------------------------ |
| `pages/`    | 首页、创作台、作品集、成品页和设置页                         |
| `core/`     | 作品模型、陶坯塑形、网格生成、场景计算、WebGL 渲染和装饰系统 |
| `services/` | 本地作品存储与匿名本地事件记录                               |
| `assets/`   | 页面背景和装饰资源                                           |
| `tests/`    | 塑形、网格、釉色和装饰逻辑测试                               |

其中 `pages/studio/studio.ts` 负责主要创作流程，`core/pottery-engine.ts` 负责渲染，`services/storage.ts` 负责作品持久化。

## 运行与检查

1. 执行 `npm install`。
2. 使用微信开发者工具导入项目根目录；预览或上传前使用有权限的小程序 AppID。
3. 执行 `npm run typecheck` 检查类型，执行 `npm test` 运行测试。

## 当前边界

当前版本是本地交互原型，尚未接入账号、云同步、服务端内容安全和后端数据服务；实际发布前仍需完成开发者工具与真机验证。
